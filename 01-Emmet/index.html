01-Emmet

Plugin for faster html. And CSS codding.

01-Child: >
Creates child elements (nesting).

Example

ul>li>a ↔️

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling: >
Creates sibling elements.

Example

section+header+nav ↔️

Result:

<section></section> <header></header> <nav></nav>

03-Multiplication: >
Repeats elements multiple times.

Example

ul>li*3 ↔️

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class: >
Creates a class attribute.

Example

menu.main ↔️

.container↔️

Result:

<menu class="main"></menu> <div class="container"></div>

05-Classes: >
Creates multiple class attributes.

Example

menu.main.upper.blue ↔️

Result:

<menu class="mainmenu uppercase blue"></menu>

06-Id: >
Creates an id attribute.

Example

nav#navigation123 ↔️

Result:

<nav id="navigation123"></nav>

07-Text: >
Inserts Text content.

Example

div{Lorem ipsum Dolor} ↔️

a{Click aqui}↔️

Result:

<div>Lorem ipsum Dolor</div> <a href="">Click here</a>

08-Custom attribute: >
Create custom attributes.

Example

a[href=www.google.com] ↔️

Result:

<a href="www.google.com"></a>

09-Item numbering: >
Adds consecutive numbers.

Example

ul>li.num$@*3 ↔️

section>article.sec$$$*3 ↔️

Result:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

10-Reverse Numbering: >
Inverts Numbering order.

Example

ul>li.num$@-*3 ↔️

Result:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

11-Base Numbering: >
Defines a base number for sequences.

Example

ul>li.num$@3*4 ↔️

Result:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb up: >
Moves up one level.

Example

Section>article>div^p↔️

Result:

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping: >
Groups elements together.

Example

(header>nav)(section>article)↔️

Result:

<header> <nav></nav> </header> <section <article></article> </section>
